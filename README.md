# property-price-prediction
This is a web application to predict property prices and weekly rent in Australia, designed to mimic the style of `realestate.com.au`. This project uses React with TypeScript, Tailwind CSS, and Vite for a modern and responsive frontend.

## Project Overview

This application allows users to:
- Select between "Buy or Selling" and "Rent" categories.
- Input property details (address, property type, size, bedrooms, bathrooms, car parks).
- Get a predicted price or rent based on simulated calculations (to be replaced with machine learning models and backend API).

The frontend is styled to resemble `realestate.com.au`, with a clean layout, navigation bar, and interactive form.

## Features

- Dynamic form based on property type (House or Apartment):
  - House: Land Size and Living Area.
  - Apartment: Total Area.
- Input fields for Bedrooms, Bathrooms, and Car Parks.
- Simulated price/rent prediction (placeholder for future API integration).
- Responsive design using Tailwind CSS.
